Circle products in use

  • USDC on Arc, the settlement asset and the gas token, with EIP-3009 authorizations so a payer can authorize without broadcasting.
  • Circle Wallets, developer controlled. In the authorized settlement mode the payer's key lives in Circle's custody and this application never holds it. The wallet signs each authorization through Circle's API and an operator submits the batch, so the wallet's transaction count stays at zero while its money moves.
